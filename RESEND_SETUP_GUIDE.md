## Overview

When a customer submits a vehicle rental request on Acelo Logistics (e.g. at `/fleet/hilux` or `/fleet/coaster-standard`), two transaction emails are triggered concurrently via Resend:

```
Customer Submits Booking Form (BookingForm.tsx)
                     │
                     ▼
       POST /api/bookings (Next.js App Route)
                     │
         ┌───────────┴───────────┐
         ▼                       ▼
Customer Confirmation    Team Dispatch Alert
Email (lib/email.ts)     Email (lib/email.ts)
  └── Sent to Customer     └── Sent to Acelo HQ
```

1. **Customer Confirmation Email:** Sent to the customer's email address with a branded header logo banner, detailed trip summary (vehicle, pickup date/time, return date/time, route, lay-over option), and social links.
2. **Team Notification Email:** Sent to Acelo Logistics HQ (`ACELO_TEAM_EMAIL`) featuring a royal blue header with bell icon, structured request overview card, and a gold "Follow Up" button linking directly to WhatsApp.

## Step 1 — Create & Access Resend Account

1. Go to [https://resend.com](https://resend.com) and log in with your Acelo Logistics work account.
2. Ensure you are in the **Acelo Logistics** project workspace.

## Step 2 — Verify Domain (`acelologistics.com`)

Resend requires DKIM and SPF verification before sending emails from your custom domain (`operation@acelologistics.com`).

### 2a. Add Domain in Resend
1. Go to **Domains** in the Resend Dashboard.
2. Click **Add Domain**.
3. Enter `acelologistics.com`.
4. Region: **US East** (or nearest).

### 2b. Configure DNS Records
Add the DNS records generated by Resend to your domain registrar (e.g. Cloudflare / Namecheap / GoDaddy):

| Type  | Name                                  | Value                                   |
| ----- | ------------------------------------- | --------------------------------------- |
| `TXT` | `resend._domainkey.acelologistics.com` | `p=MIGfMA0GC...` (from dashboard)       |
| `MX`  | `send.acelologistics.com`             | `feedback-smtp.us-east-1.amazonses.com` |
| `TXT` | `send.acelologistics.com`             | `v=spf1 include:amazonses.com ~all`     |

> ⚠️ Always copy exact values from your Resend dashboard.

## Step 3 — Generate API Key

1. Go to **API Keys** in the Resend Dashboard.
2. Click **Create API Key**.
3. Key Name: `acelo-website-booking`.
4. Permission: **Sending access** (Domain: `acelologistics.com`).
5. Copy the key (`re_...`).

---

## Step 4 — Configure Environment Variables

In `.env.local` at the root of the project, add:

```env
# ──────────────────────────────────────────────────────
# Resend Email Configuration — Acelo Logistics
# ──────────────────────────────────────────────────────

# Active Resend API key
RESEND_API_KEY=re_xxxxxxxxxxxxxxxxxxxxxxxx

# Verified Sender Email
RESEND_FROM_EMAIL="Acelo Logistics <operation@acelologistics.com>"

# Acelo HQ Dispatch Inbox (receives internal rental alerts)
ACELO_TEAM_EMAIL=treasure.o@acelologistics.com

# Site base URL for asset resolution
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

> 🔐 **Security Warning:** Never commit `.env.local` to Git. Keep real API keys in `.env.local` or host environment variables (Vercel / Netlify).

## Step 5 — Email Architecture in Acelo Codebase

Key files involved in the email flow:

| File Path | Role & Description |
| --------- | ------------------ |
| `app/api/bookings/route.ts` | Serverless API route handling POST booking submissions and calling Resend email dispatch functions. |
| `lib/email.ts` | Contains email template generators (`customerConfirmationEmailHtml`, `teamNotificationEmailHtml`), Base64 embedded email assets, and `sendCustomerConfirmationEmail` / `sendTeamNotificationEmail`. |
| `lib/booking.ts` | Payload verification, formatters, and WhatsApp pre-filled message generator (`buildWhatsAppMessage`). |
| `components/booking/BookingForm.tsx` | Interactive booking form with custom `DatePicker`, `TimePicker`, `LocationAutocompleteInput`, and `SuccessModal`. |

## Best Practices & Deliverability

* **Base64 Embedded Assets:** Email logos and social media icons (`social-whatsapp.png`, `social-instagram.png`, `social-linkedin.png`) are automatically converted to Base64 data URIs in `lib/email.ts`. This guarantees images render in all email clients (Gmail, Outlook, Apple Mail) without relying on external CDNs during early development.
* **Concurrent Execution:** `Promise.allSettled` is used in `/api/bookings` so that a failure in one email does not block the customer's booking confirmation modal.
* **Strict Validation:** Phone numbers and email formats are validated on both client and server before dispatching emails.

## Troubleshooting

### "Email not arriving in customer inbox"
- Check spam/junk folder.
- Ensure `RESEND_FROM_EMAIL` matches the verified domain (`acelologistics.com`).
- Verify domain DNS status is active green in the Resend dashboard.

### "Module not found: Can't resolve 'resend'"
- Run `npm install resend` in your terminal.
